# ⚡ AuraFit PWA

> **Progressive Web App Mobile-First de Biohacking, Hábitos Saludables, Nutrición Inteligente por Despensa & Entrenamiento Híbrido Adaptativo.**

Diseñado con los estándares de diseño e ingeniería ergonómica de **Emil Kowalski** (`100dvh`, retroalimentación háptica `:active { transform: scale(0.96) }`, safe areas de iPhone y entradas de 16px para evitar auto-zoom en iOS Safari).

---

## 🚀 Características Principales

1. **⚡ Hábitos & Biohacking Diario:**
   - Tracking con micro-animaciones para Creatina Monohidrato (5g) y sesiones Mindvalley / crecimiento personal.
   - Hidratación con electrolitos y descanso reparador.
   - Sincronización automática con bot de Telegram (`@mi_antigravity_pc_bot`) para recordatorios preventivos a las 18:00.

2. **🥗 Nutrición Inteligente & Despensa:**
   - Motor metabólico con fórmula **Mifflin-St Jeor** para **Lean Bulk** (+300 kcal superávit limpio).
   - Generador de comidas en base a ingredientes reales de cocina con desglose instantáneo de macronutrientes (Proteína 2.0g/kg, Grasas 0.9g/kg, Carbohidratos balance).
   - 🚨 **Botón SOS Damage Control (Post-Comida Chatarra):** Protocolo metabólico de 4 pasos (caminata posprandial para translocación de GLUT-4, hidratación osmótica y pivote proteico sin ayunos punitivos).

3. **💪 Entrenamiento Híbrido Adaptativo:**
   - **Gimnasio:** Sobrecarga progresiva (Push / Torso), control de RIR y descansos guiados.
   - **En Casa / Viaje:** Rutina metabólica de alta densidad **EMOM 30 Minutos** (cero equipamiento necesario).
   - Seguimiento de peso corporal con **Media Móvil Semanal** y gráfica SVG para filtrar fluctuaciones por retención de agua.

---

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 16 (App Router)
- **Estilos:** 100% Vanilla CSS Modular (Dark Theme `#0A0E1A`)
- **Persistencia:** Dual Neon PostgreSQL Serverless + LocalStorage Sync
- **PWA:** Service Worker y Web Manifest standalone
